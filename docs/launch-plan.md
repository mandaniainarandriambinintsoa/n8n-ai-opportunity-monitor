# Launch plan

## Asset URLs and UTM conventions

| Channel | URL parameters |
|---|---|
| GitHub repository | `utm_source=github&utm_medium=repository&utm_campaign=ai-opportunity-monitor` |
| n8n template | `utm_source=n8n&utm_medium=template&utm_campaign=ai-opportunity-monitor` |
| n8n community | `utm_source=n8n&utm_medium=community&utm_campaign=ai-opportunity-monitor` |
| Reddit | `utm_source=reddit&utm_medium=community&utm_campaign=ai-opportunity-monitor` |
| LinkedIn | `utm_source=linkedin&utm_medium=social&utm_campaign=ai-opportunity-monitor` |
| Guest article | `utm_source=SOURCE_NAME&utm_medium=referral&utm_campaign=ai-opportunity-monitor` |

## Publication order

1. Test the workflow manually with a safe RSS feed.
2. Publish the GitHub repository.
3. Submit the workflow to n8n Creator Hub.
4. Publish the technical case study in the n8n community.
5. Answer relevant community questions before sharing on Reddit.
6. Publish the build story on LinkedIn.
7. Pitch the case study to ten relevant newsletters, blogs or podcasts.

## 30-day measurement

Review each week:

- referring domains and links in Google Search Console;
- referral sessions by UTM source;
- template page views and copies;
- GitHub views, clones and stars;
- engaged sessions and 75% scroll events in PostHog;
- contact CTA clicks and successful form submissions;
- qualified conversations attributed to the campaign.

Do not evaluate the campaign only by backlink count. A relevant template copy, a qualified conversation or a branded search can be more valuable than several low-quality directory links.
